# WSTD-BALL-NONE-NONE Assembly Baseline

This is the minimum serviceable assembly order for the first wand hardware drop.

## Required Tools

- ESD-safe tweezers
- Fine-tip soldering iron and hot-air rework station
- Calipers
- Non-marring spudger
- Small vise or soft jaws for tube/end-cap handling

## Critical Build Constraints

- Tip module and rear end cap must be separately removable.
- Battery replacement must not require destroying the tip module.
- Barrel switch replacement must not require crushing or permanently deforming
  the tube body.
- The ball path must remain cleanable.

## Intended Assembly Order

1. Verify the protected LiPo cell size and route it to a serviceable battery bay.
2. Populate the rigid PCB or carrier, documenting switch and Hall-sensor
   orientation.
3. Assemble the tip module so the ball and roller system can be removed for
   cleaning or replacement.
4. Install the barrel switch with a retention method that remains serviceable.
5. Install the battery using removable adhesive or a removable cradle.
6. Close the rear USB-C end cap with a reversible retention method.
7. Record final mass, balance point, and any material choices that affect skin
   comfort or tremor damping.

## Assembly Record To Capture

- Tube material and wall thickness
- Tip-module retention method
- Switch model actually used
- Battery dimensions and supplier
- Closure methods at tip and rear cap
