# R30-BALL-NONE-NONE Assembly Baseline

This is the minimum non-destructive assembly order the first ball+Hall ring
design must support.

## Required Tools

- ESD-safe tweezers
- Fine-tip soldering iron and hot-air rework station
- Non-marring spudger
- Magnification suitable for Hall-sensor orientation checks
- Calipers

## Critical Build Constraints

- The ball must be removable for cleaning and replacement.
- The roller and magnet stack must be positively located, not free-floating on
  adhesive alone.
- Battery installation must still use removable adhesive and a reopenable seam.
- Hall sensors must be installed with known polarity and channel mapping.

## Intended Assembly Order

1. Verify battery paperwork and physical envelope before locking the shell.
2. Populate the PCB or carrier assembly, especially the Hall sensors, with
   orientation documented for later service.
3. Assemble the roller and magnet subcomponents so a failed roller can be
   swapped without replacing the whole shell.
4. Install the ball socket and confirm the ball can be inserted and removed
   without cracking the shell.
5. Install the click element so click-service does not require disturbing the
   tracking ball path.
6. Install the battery with removable adhesive and route wiring clear of the
   ball cavity and service seam.
7. Close the shell with a reversible seam.

## Assembly Record To Capture

- Ball material and source
- Roller spindle and magnet dimensions
- Hall sensor orientation map
- Final ball protrusion and free-spin notes
- Closure method and any adhesive used
